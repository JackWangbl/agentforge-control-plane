# 输出字段与口径

| 字段 | 说明 |
| --- | --- |
| offer_id | 1688 商品 ID，可从详情 URL 提取 |
| 商品标题 | 页面原始标题，必要时附中文归纳 |
| 款式 | 方巾、长巾、包头帽、头巾帽等 |
| 材质/工艺 | 雪纺、棉、涤纶、提花、烫钻等 |
| 品牌 | 只填页面明确标注的品牌；否则“未标注” |
| 供应商 | 企业主体名称 |
| 店铺 | 店铺名或卖家登录名，与品牌分开 |
| 价格 | 页面展示的阶梯价或区间价，保留币种 |
| 起订量 | 最小采购数量及单位 |
| 销量数值 | 只记录页面明确显示的数值 |
| 销量单位 | 件、条、笔等 |
| 销量周期 | 累计、近 30 天或页面所示周期；未知则填“页面未说明” |
| 销量状态 | 已核验、未公开、动态加载不可验证、需登录验证 |
| 非销量指标 | 复购率、评价数、产能等，单独记录且不能用于销量排名 |
| 来源 URL | 优先使用 1688 商品详情链接 |
| 来源类型 | 1688 原始页、搜索页、供应商页、第三方镜像 |
| 采集时间 | 使用 ISO 日期与时区 |

## 判定规则

- “已售”后有明确数字：可记录为销量，并保留单位和页面口径。
- 只出现“已售”标签但没有数字：销量状态写“动态加载不可验证”。
- “回头率 62%”：属于复购指标，不是销量。
- “年产 480000 条”：属于生产能力，不是销量。
- 品牌缺失但供应商存在：品牌填“未标注”，供应商照实记录。
