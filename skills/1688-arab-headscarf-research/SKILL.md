# 1688 阿拉伯头巾调研

## 工作流程

1. 记录采集日期、搜索关键词和筛选条件。默认同时搜索：`阿拉伯头巾`、`穆斯林头巾`、`沙特头巾`、`阿拉伯方巾`、`hijab`。
2. 优先访问 1688 搜索结果和商品详情页。遇到登录、验证码或动态字段时，使用可交互浏览器；无法通过时明确记录阻断原因，不猜测数据。
3. 每个商品至少采集：商品标题、详情链接、款式、材质、颜色/图案、适用人群、品牌、供应商/店铺、价格区间、起订量、销量、销量口径、采集时间。
4. 将品牌、供应商、店铺名严格分列。页面没有品牌字段时填写“未标注”，不得把公司名或旺旺登录名当作品牌。
5. 只有页面明确展示的“已售/成交件数/成交笔数”可写入销量。复购率、评价数、收藏数、年产能和月产能均不得换算或冒充销量。
6. 对数据去重。同一 offer ID 只保留一条；同款不同供应商可分别保留。
7. 生成表格和简短结论，注明销量排序基于哪一种口径。无法获得数值销量时仍输出已核验的款式和品牌信息，并把销量写为“未公开/当前不可验证”。

## 输出要求

使用 `references/output-schema.md` 的字段和口径。报告应包含：

- 查询范围与时间
- 商品明细表
- 款式归类与品牌/供应商分布
- 按可比销量排序的热销项；没有可比销量时说明原因
- 数据限制与需要人工登录验证的项目
- 每条数据的 1688 原始链接；使用转载或镜像页时额外标注来源类型

不得声称结果代表 1688 全站销量。销量属于时点数据，报告中必须保留采集日期。
